# EyesOnRoad

## Sobre o projeto

O **EyesOnRoad** é um sistema desenvolvido para auxiliar na prevenção de acidentes causados pela sonolência ao volante.

O projeto utiliza uma câmera para monitorar o motorista e identificar sinais de sonolência, como **fechamento dos olhos e bocejos**. Quando o sistema identifica que os olhos permanecem fechados por **5 segundos**, um alarme é acionado para alertar o motorista.

Além do sistema de monitoramento, o projeto conta com uma plataforma web que permite o cadastro e login de usuários, visualização de gráficos de alertas e acesso a dicas de segurança no trânsito.

## Como funciona

```text
Câmera
   ↓
Monitoramento do motorista
   ↓
Detecção dos olhos e bocejos
   ↓
Identificação de sonolência
   ↓
Olhos fechados por 5 segundos
   ↓
Alarme
   ↓
Registro do alerta
   ↓
Dashboard
```

## Segurança

O EyesOnRoad também disponibiliza dicas para ajudar os motoristas a evitar situações de risco relacionadas à sonolência, como a importância de descansar antes de dirigir e realizar pausas durante viagens longas.
